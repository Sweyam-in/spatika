# Spatika 2.4 → 2.5 migration

## Drop Tailwind: `@spatika/utilities`

Apps that compiled Spatika through Tailwind can remove it. Install the compiler:

```bash
npm install @spatika/tokens@2.5 @spatika/react@2.5
npm install -D @spatika/utilities@2.5
npm uninstall tailwindcss @tailwindcss/vite @tailwindcss/postcss @tailwindcss/typography tw-animate-css
```

Stylesheet — replace `@import "tailwindcss"`, `@source`, `@plugin` and any `@theme` block:

```css
@import "@spatika/utilities/preflight.css"; /* the Tailwind v4 reset */
@import "@spatika/tokens/styles.css";

@spatika utilities;

/* app styles and overrides */
```

Put `@spatika utilities;` in the stylesheet your JavaScript imports, after its `@import`s.

Build config:

```ts
// vite.config.ts
import spatikaUtilities from "@spatika/utilities/vite";
plugins: [spatikaUtilities(), react()]
```

```js
// postcss.config.mjs (Next.js)
export default { plugins: { "@spatika/utilities/postcss": {} } };
```

Move `@theme` entries that are not Spatika defaults into the plugin's `theme` option
(`theme: { colors: { brand: "var(--brand)" }, fontFamily: { sans: "var(--font-ubuntu)" } }`).
Replace `@apply` with plain declarations and `--tw-*` variables with `--spk-u-*`.
Enable `typography: true` for `prose` classes. Enter/exit animations (`animate-in fade-in
zoom-in-95 slide-in-from-top-2`) are built in.

Apps that only import `@spatika/tokens/styles.css` keep working; adding the plugin also generates
the utility classes in their own markup that the prebuilt layer does not include.

## Visual changes to review

| Change | 2.4 | 2.5 |
|---|---|---|
| `--spk-control-border` | tertiary-text mix (≥ 3:1) | `--spk-border`; ≥ 3:1 with `data-contrast="more"` or `prefers-contrast: more` |
| `space-*`, `divide-*` in the prebuilt layer | margin/border on the following sibling | on the preceding sibling (Tailwind v4) — can shift layout by 1px |
| `translate-*`, `scale-*` in the prebuilt layer | composed into `transform` | `translate` / `scale` properties, so they combine with transform animations |
| Prebuilt utilities | unlayered | `@layer utilities` — unlayered app CSS now wins over them |
