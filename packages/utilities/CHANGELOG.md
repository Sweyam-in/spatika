# @spatika/utilities

## 2.6.0

### Minor Changes

- Liquid glass material (Apple-inspired) across every component (new `liquid.css`: content, control and floating densities, plus an ambient canvas wash), and for `.spk-glass` / `Card surface="glass"`: lensed rim, specular sheen, wider blur, plus a `data-variant="clear"` media variant. Tint density and glass-scoped text colours are tuned so text keeps WCAG AA over any backdrop; the previous 0.72 tint did not. Charts pick up the same material: chart interaction states (`chart-interaction.ts`, `charts.css`) and the 3D, flow and radial composites are adjusted to sit on glass surfaces.

## 2.5.0

### Minor Changes

- Apps no longer need Tailwind. The new `@spatika/utilities` package generates the utility classes an app uses (`flex`, `md:grid-cols-3`, `bg-surface/80`, `data-[state=open]:flex`, `[&>svg]:size-4` …) from Spatika tokens, through a Vite plugin or a PostCSS plugin (Next.js). Class names and output follow Tailwind CSS v4, so existing markup renders unchanged; apps add their own colours, fonts and radii through the `theme` option and keep their CSS overrides after `@spatika utilities;`. It also ships a Tailwind-compatible `preflight.css`, `prose` typography (opt-in) and enter/exit animation utilities.

  **Tokens.** The prebuilt utility layer in `@spatika/tokens/styles.css` is now generated by the same compiler (in `@layer utilities`, so app CSS overrides it without `!important`) and covers the classes it shipped before. Utility semantics now match Tailwind v4: `space-*` / `divide-*` apply to the preceding sibling, `translate-*` / `scale-*` use the individual `translate` / `scale` properties, and bare `ring` uses Spatika's focus colour.

  **Control borders.** Inputs, checkboxes, radios and switch tracks use the quiet theme border again by default. The high-contrast (WCAG 1.4.11, ≥ 3:1) boundary from 2.4 is opt-in: set `data-contrast="more"` on `<html>` or a container; it also turns on when the OS asks for more contrast (`prefers-contrast: more`), unless `data-contrast="normal"`.
