# Third-party notices

`@spatika/utilities` generates utility classes whose names and output follow the
Tailwind CSS v4 conventions, so apps can move off Tailwind without changing their markup.
The default colour palette (`src/palette.ts`), the preflight reset (`src/preflight.css`)
and the default scales in `src/theme.ts` are derived from Tailwind CSS and
`@tailwindcss/typography` / `tw-animate-css` defaults.
